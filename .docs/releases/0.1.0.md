# Release 0.1.0 — 2026-10-11

The initial Transcend scaffold establishes a modular logistics ERP foundation, public marketing pages, and a reproducible local development environment for the team.

## New features

- **Frontend foundation:** React 19, Vite, TypeScript, Tailwind CSS 4, daisyUI 5, TanStack Query, React Hook Form, and Zod, with shared UI and domain module boundaries.
- **Marketing pages:** Responsive landing, product, solutions, and contact pages, including an interactive workflow preview and a validated browser-local operations brief with text download.
- **Workspace preview:** Routes under `/app` with placeholders for the business modules; existing module URLs remain available.
- **Backend foundation:** NestJS domain modules with request validation, JWT verification, permission and organization membership checks, sanitized errors, and health endpoints.
- **Database baseline:** A versioned TypeORM migration creates the 22-table MariaDB schema, with explicit foreign-key indexes and documented decimal precision. Automatic schema synchronization is disabled.
- **Container setup:** Backend/frontend Dockerfiles, an NGINX API proxy, and Docker Compose services with health checks, migration ordering, persistent database storage, and a hot-reload development configuration.
- **Team workflow:** Tracked architecture and engineering documentation in `.docs`, module ownership guidance, independent development instructions, formatting settings, and build/lint/test commands.

## Scope

This release provides infrastructure and previews. Business CRUD, login and refresh flows, role seeds, resource ownership policies, and financial operations remain future work. The contact page does not send email or submit leads to an API.

Local environment files, secrets, dependencies, build outputs, and browser verification artifacts are excluded from Git. The Compose setup targets local development.

## Validation

- Backend and frontend builds and lint checks passed.
- Backend HTTP security and error sanitization tests passed.
- Docker startup and readiness checks passed.
- Browser checks covered public and workspace routes, desktop/mobile layouts, the workflow switcher, form validation, and brief downloads.
